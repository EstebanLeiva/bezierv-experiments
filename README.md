# bezierv-experiments — Reproducibility scripts for the paper

Command-line scripts that regenerate every data-derived figure and table in the
paper *Computational Framework for Bézier Distributions*. Each artefact is
regenerated by the single script listed below (one script may emit more than one
artefact).

## What each script reproduces

Ordered by appearance in the paper. Figure/Table numbers follow the current
draft; the LaTeX labels (e.g. `tab:MDEtab`, `fig:restrictioneval`) are stable if
the numbers drift.

| Paper reference        | What it is                                                            | Script                     | Output                                                              |
|------------------------|----------------------------------------------------------------------|----------------------------|--------------------------------------------------------------------|
| §6.2 · Fig. 5          | Bézier fit of the 4-cavity multimodal mixture (PDF/CDF + control pts) | `fig_multimodal.py`        | `figures/multimodal.pgf`                                           |
| §6.2 · Table 1         | Descriptive statistics: sample vs. Bézier fit                        | `tab_multimodal.py`        | `tables/multimodal_stats.tex`                                     |
| §6.2 · Fig. 6b–6c      | Hand-adjusted Bézier r.v. and histogram of its variates              | `fig_multimodal_manual.py` | `figures/multimodal_manual.pgf`, `figures/multimodal_manual_hist.pgf` |
| §7.1 · Table 2         | MLE comparison — Bézier vs. Beta vs. Johnson (synthetic)             | `tab_synthetic.py`         | `tables/syntheticmle.tex`                                         |
| §7.1 · Table 3         | MSE comparison — PGD vs. IPOPT vs. Nelder–Mead (synthetic)           | `tab_synthetic.py`         | `tables/syntheticmse.tex`                                         |
| §7.2 · Table 4         | Chicago travel-time descriptive statistics per regime                | `tab_real_stats.py`        | `tables/realdist.tex`                                            |
| §7.2 · Table 5         | MLE comparison (Chicago transportation data)                         | `tab_real_mle.py`          | `tables/realmle.tex`                                            |
| §7.2 · Table 6         | MSE comparison (Chicago transportation data)                         | `tab_real_mse.py`          | `tables/MDEtab.tex`                                             |
| §7.3 · Fig. 7          | Restriction quality vs. degree — empirical $\mathcal{O}(1/n)$ rate    | `fig_restriction_rate.py`  | `figures/restriction_rate.pgf`                                   |
| §8 · Fig. 8a–8b        | S-αRP optimal path + path travel-time distribution                   | `exp_sarp.py`              | `figures/sarp_path_grid.pgf`, `figures/sarp_path_dist.pgf`       |

Table scripts also write a long-format `*_raw.csv` alongside the `.tex`;
`tab_real_mse.py` and `fig_restriction_rate.py` additionally checkpoint to CSV so
an interrupted run can resume.

**Not reproduced here** (no experimental data behind them): Figures 1–2 (TikZ
Bézier cdf/pdf illustrations), Figure 3 (TikZ package diagram), Figure 4 (the
code listing), and Figure 6a (a screenshot of the interactive fitting component,
`figures/interactive.png`).

## Setup

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

The S-αRP application (`exp_sarp.py`) additionally needs `pulsekit`, the pulse
algorithm package, which is not on PyPI — install it from source:

```bash
pip install git+https://github.com/EstebanLeiva/pulsekit
```

The Chicago dataset (`data/Chicago_main.json`, ≈280 MB) is the timestamped raw
data used by `tab_real_*` and `exp_sarp.py`. It is not bundled with this
repository; download it from Zenodo (CC BY 4.0) and place it under `data/`:

> Goerigk, M., Hartisch, M., Merten, S., & Miehlich, A. (2025). *Chicago Graph
> and Travel Time Data* (v1) [Data set]. Zenodo.
> https://doi.org/10.5281/zenodo.15267992

## Smoke mode vs. paper-faithful runs

Three scripts default to a small subset so iteration is fast; pass the
documented flag to regenerate the paper-faithful numbers:

```bash
# Tables 2, 3 (synthetic):   3 instances/family  ->  200 instances/family
python tab_synthetic.py --n-per-family 200

# Tables 5, 6 (Chicago):     20 arcs/regime   ->  all arcs (~1086/regime)
python tab_real_mle.py --max-arcs 0
python tab_real_mse.py --max-arcs 0
```

The remaining scripts already default to paper-faithful settings. Four are
always fast; for the last two a flag instead gives a *quicker* run:

```bash
# §6.2 (multimodal example) and Table 4 (stats): always paper-faithful, and fast
python fig_multimodal.py            # Fig. 5
python fig_multimodal_manual.py     # Fig. 6b-6c
python tab_multimodal.py            # Table 1
python tab_real_stats.py            # Table 4

# Fig. 7 (restriction rate, O(1/n)): default reproduces it (slow; resumable)
python fig_restriction_rate.py                       # paper-faithful
python fig_restriction_rate.py --n-reps 3 --n-max 30 # quick look

# Fig. 8 (S-aRP): default uses the full Chicago network
python exp_sarp.py                                   # paper-faithful
python exp_sarp.py --regime full_day --max-arcs 200  # smoke run on a subset
```

### Regenerate every artefact

```bash
python fig_multimodal.py
python fig_multimodal_manual.py
python tab_multimodal.py
python tab_synthetic.py --n-per-family 200
python tab_real_stats.py
python tab_real_mle.py --max-arcs 0
python tab_real_mse.py --max-arcs 0
python fig_restriction_rate.py
python exp_sarp.py
```

## Wiring outputs back into the paper

Tables emit a complete `\begin{table}...\end{table}` block.

Figures emit a `.pgf` file (for `\input{}` into the paper) and a sibling `.png`
of the same name for quick visual inspection without compiling LaTeX.

## Reproducibility notes

- All scripts accept `--seed` (default `42`). The synthetic and S-αRP runs are
  deterministic given the seed. The Chicago lognormal synthesis (used only for
  arcs with a single unique observation) is also seeded.
- `fig_restriction_rate.py` and `tab_real_mse.py` checkpoint to CSV as they go,
  so re-invoking with the same arguments resumes an interrupted run (pass
  `--no-resume` / `--fresh` respectively to start over).
